AZIMI SHOP

This version includes:
- Hidden admin panel in the same index.html (Ctrl+A then Z)
- 7 weekly bonus slots with product/prize name and image upload
- Selectable weekly winner; the wheel always lands on the selected winner for the week
- Afghanistan provinces map in the 34-province section
- High-contrast premium light mode and 2-second theme transition
- Existing store, cart, WhatsApp ordering, multilingual sidebar, and product image upload preserved

Important:
This is a browser-only/static project. localStorage settings are local to the browser/device. If the weekly bonus winner must be synchronized for every customer on every device, a server/database is required.
